# grammar.md — spelling, spacing and sentence grammar of 공문 text

Rule ids `G##`. Source ids are in `sources.md`. Main sources: S01 §3 "공공언어 바로 쓰기 참고사항" and §6 나.2) "작성 시 유의사항" (2025 편람), and S05 (한글 맞춤법, a 고시). Examples marked "written for this skill" are not from a source. "convention" = no official source states it.
Use this file while you write and again in the final check (`checklist.md`).

## 1. Content: 정확성, 용이성, 성실성  [S01 §6 나.2)]
| Id | Rule | Example | Source |
|---|---|---|---|
| G01 | Write by the 6하 원칙 (who, when, where, what, how, why). Leave out no needed fact. No wrong numbers, no typos. | – | S01 §6 나.2) 가) |
| G02 | Do not write a sentence that can be read two ways. Give number, rank, unit and role. | Bad: `광복절 기념행사에 직원 2명을 참석하도록 하시기 바랍니다.` (2 people of which rank? per team or per bureau? guests or helpers?) Good (written for this skill, not from S01): `과별로 6급 이하 직원 2명을 행사 참석자로 정하여 …` | S01 §6 나.2) 가) |
| G03 | Do not distort facts with vague or exaggerated words. | – | S01 §6 나.2) 가) |
| G04 | Write from the reader's side. Short sentences, split into items. Conclusion first, then reasons. Concrete words, not abstract ones. | – | S01 §6 나.2) 나), S10 p.179 |
| G05 | Use polite words; nothing that offends or looks down on the reader; no emotional or overbearing words even to a lower office (`…할 것`, `…하기 바람` -> `…하시기 바랍니다`). | – | S01 §6 나.2) 다) |

## 2. Spelling (어문 규범)  [S01 §3 2.가, S05]
| Id | Rule | Wrong -> right | Source |
|---|---|---|---|
| G10 | 두음 법칙: 녀·뇨·뉴·니 at the start of a word -> 여·요·유·이. `연도` is its own word. | `남여 -> 남녀`, `년간 -> 연간`, `회계 년도 -> 회계 연도`, `시설 년도 -> 시설 연도` | S01 §3, S05 제10항 |
| G11 | `-률/-율`: after a vowel or ㄴ write `율`, else `률`. | `자부담율 -> 자부담률`, `집행율 -> 집행률`; `백분율`, `비율` are right | S01 §3, S05 제11항 |
| G12 | 사이시옷: write it in native or mixed compounds with a tense sound; not in Chinese-character-only compounds except 곳간·셋방·숫자·찻간·툇간·횟수. | `하교길 -> 하굣길`, `수도물 -> 수돗물`, `최소값 -> 최솟값`, `둘쨋날 -> 둘째 날`, `칫과 -> 치과`, `갯수 -> 개수`, `회수(차례) -> 횟수`; `머리말`, `셋방` are right | S01 §3, S05 제30항 |
| G13 | Frequent misspellings. | `일사분란 -> 일사불란`, `청럼도 -> 청렴도` | S01 §3 |
| G14 | Loanword spelling (외래어 표기법). | `컨퍼런스 -> 콘퍼런스`, `솔루션 -> 설루션`, `서포터즈 -> 서포터스`, `숏폼 -> 쇼트 폼`, `메세지 -> 메시지`, `뱃지 -> 배지`, `어플리케이션 -> 애플리케이션`, `워크샵 -> 워크숍`, `파트너쉽 -> 파트너십` | S01 §3 |
| G15 | Particle after parentheses follows the letter before the bracket. | `19일(토)는 -> 19일(토)은`, `권고(안)을 -> 권고(안)를`, `인공지능(AI)를 -> 인공지능(AI)을`, `지역청(☎000-0002)로 -> 지역청(☎000-0002)으로` | S01 §3 (= notation N09) |
| G16 | No 가운뎃점 inside a word that the dictionary has as one word. | `국내·외 -> 국내외`, `상·하수도 -> 상하수도`, `민·관 -> 민관`, `시·도 -> 시도`, `초·중·고 -> 초중고`, `출·퇴근 -> 출퇴근` | S01 §3 (= N11) |
| G17 | More spelling: `-이/-히` endings of adverbs; 두음 법칙 in compounds with `년`; `-율/-률` (G11). Examples written for this skill. | `꼼꼼이 -> 꼼꼼히`, `년수 -> 연수`, `경쟁율 -> 경쟁률`, `출산률 -> 출산율` | S05 제51항, 제10항, 제11항 |
| G18 | Chinese characters and Roman letters never stand alone in public text; write Hangul first, the original in parentheses only when needed. | `AI 로봇 -> 인공 지능(AI) 로봇`, `일반 전형 합격자 限 -> 일반 전형 합격자에 한함`, `對美 수출 -> 대미 수출` / `미국 대상 수출`; written for this skill: `p21 -> 21쪽`, `E-mail -> 전자우편` | S15 (국어기본법 제14조, 시행령 제11조), S01 §3 1.가.1) |
| G19 | Quotation marks and brackets: `“ ”` for direct speech or a quoted text; `‘ ’` for a quote inside a quote or for emphasis; `「 」` for names of laws, rules and small titles; outer `[ ]` around brackets that already hold `( )`. The title in a related-document citation is in `“ ”` (S01 §5 다.2)). Examples written for this skill. | `‘쉬운 말 쓰기’ 운동`, `「국가를 당사자로 하는 계약에 관한 법률」`, `[신청 기간(평일 09:00~18:00) 안에 제출]` | S05 (문장 부호: 큰따옴표, 작은따옴표, 홑낫표, 대괄호), S01 §5 다.2) |

## 3. Spacing (띄어쓰기)  [S01 §3 2.나, S05]
| Id | Rule | Wrong -> right | Source |
|---|---|---|---|
| G20 | Space between words. | `가야할지 -> 가야 할지`; `기재여부 -> 기재 여부`; `사진위의 날인여부 -> 사진 위의 날인 여부` | S01 §3 나.1) |
| G21 | Nouns with their own meaning are spaced. | `자전거열차운행 -> 자전거 열차 운행` | S01 §3 나.2) |
| G22 | Dependent nouns and unit nouns are spaced from the word before: 달러·원·명·톤, 데 (place/case), 시 (time), 간 (between). `간` for a period of time is a suffix (attached). | `296억달러 -> 296억 달러`, `10만톤 -> 10만 톤`, `오십명 -> 오십 명`, `폐기하는데 O개월 -> 폐기하는 데 O개월`, `지원시 -> 지원 시`, `어겼을시에는 -> 어겼을 시에는`, `기관간 -> 기관 간`; but `이틀간`, `한 달간` | S01 §3 나.3) |
| G23 | Particles attach to the word before. | `지방공무원 뿐만 아니라 -> 지방공무원뿐만 아니라` | S01 §3 나.4) |
| G24 | Prefixes attach to the next word; suffixes attach to the word before. | `비 공개 -> 비공개`, `재 교육 -> 재교육`, `50여명 -> 50여 명`, `내일 쯤 -> 내일쯤`, `일주일 가량 -> 일주일가량`; `제1 과` (principle) / `제1과` (allowed) | S01 §3 나.5) |
| G25 | A name attaches to the family name; titles and job names are spaced. | `홍길동씨 -> 홍길동 씨`, `행정안전부장관 -> 행정안전부 장관` | S01 §3 나.6) |
| G26 | A determiner (관형사) is spaced from the next word; as a prefix it attaches. Prefer native `이` to `본`. | `본제도 -> 본 제도` (better: `이 제도`), `총300대 -> 총 300대`; but `총감독`, `총결산`, `총면적` | S01 §3 나.7) |
| G27 | Colon and range mark spacing. | `원장 : 김갑동 -> 원장: 김갑동`, `4. 23. ~ 6. 15. -> 4. 23.~6. 15.` | S01 §3 나.8) (= N08, N06) |
| G28 | Date: a period after year, month and day. | `’26. 1 -> ’26. 1.`, `2023. 6. 27(화) -> 2023. 6. 27.(화)` | S01 §3 나.9) (= N02, N03) |
| G29 | Quick lists below: the S01 examples plus the 한글 맞춤법 rules on dependent nouns (제42항), units (제43항), connecting words (제45항) and auxiliary verbs (제47항). Examples not in S01 are written for this skill. | see below | S01 §3 나., S05 제2항, 제41항-제47항 |

**G29 quick list — spaced (띄어 씀)**: dependent nouns and time words: `지원 시`, `승인 후`, `기한 내`, `추진 중인`, `기관 간` (= between), `폐기하는 데`, `밝힌 바와 같이`, `기재 여부`; separate words: `15세 이상`, `3년 이하`; connecting words: `국장 겸 과장`, `개발 및 관리`, `활용반 등`; unit nouns after 만·천·억 or `-여`: `296억 달러`, `10만 톤`, `50여 명`; determiners: `총 300대`, `이 제도`; titles: `홍길동 씨`, `행정안전부 장관`; auxiliary verbs (spaced in principle, attached allowed): `알려 드립니다`, `보내 주시기 바랍니다`.
**G29 quick list — attached (붙여 씀)**: suffixes and prefixes: `이틀간`, `한 달간` (period `-간`), `내일쯤`, `일주일가량`, `50여`, `비공개`, `재교육`, `제1과` (allowed; principle `제1 과`); particles: `지방공무원뿐만`, `것뿐`; numbers with plain Arabic digits and their unit (allowed): `28건`, `15세`, `108명`, `계획서 1부`.

Note on units (= N13): space the unit noun after a Hangul number unit or `-여` (`10만 톤`, `50여 명`), as S01 corrects; after plain Arabic digits it may attach (`28건`, `108명`), as 한글 맞춤법 제43항 allows.

## 4. Sentence grammar (어법)  [S01 §3 2.다]
| Id | Rule | Wrong -> right | Source |
|---|---|---|---|
| G30 | Subject, object and predicate must match (호응). | `문제는 … 이용할 수 없다. -> 문제는 … 이용할 수 없다는 것이다.`; `주요 교육 내용으로는 …, … 등으로 구성된다. -> 주요 교육 내용으로는 …, … 등이 있다.` | S01 §3 다.1) |
| G31 | Joined parts must be of the same kind (noun + noun, clause + clause). | `인재 양성과 어려운 이웃을 돕기 위해 -> 인재 양성과 어려운 이웃 돕기를 위해` / `인재를 양성하고 어려운 이웃을 돕기 위해` | S01 §3 다.2) |
| G32 | Pick the word with the right meaning: the applicant `제출`s, the office `접수`s. | `양식을 작성해 전자우편으로 접수하면 된다 -> … 제출하면 된다` | S01 §3 다.3) |
| G33 | Particles: `으로서` = as (a role), `으로써` = by means of. | `공공기관으로써 -> 공공기관으로서`; `현장에 상황을 -> 현장의/현장에서 상황을` | S01 §3 다.4) |
| G34 | Endings: use the modifier form before a noun. | `학생들을 위해 … 지원은 -> 학생들을 위한 … 지원은` | S01 §3 다.5) |
| G35 | Do not drop a needed part. | `더불어 연초에 … -> 이와 더불어 연초에 …`; `지역(3자리), 국(4자리), 번호(4자리)로 수록 -> … 번호(4자리)의 순서대로 수록` | S01 §3 다.6) |
| G36 | Say it positively; avoid double negation. Examples written for this skill. | `다시 검토하지 않을 수 없습니다 -> 다시 검토해야 합니다`, `참석하지 않는 직원이 없도록 -> 모든 직원이 참석하도록` (checker: T031) | convention; S01 §6 나.2) 가) (one clear reading) |

## 5. Plain Korean (쉽게 쓰기)  [S01 §3 1.가]
| Id | Rule | Wrong -> right | Source |
|---|---|---|---|
| G40 | Hard words -> easy words. | `사용료를 일할 계산하여 -> 사용료를 날수에 따라 계산하여` (S01 also gives `날짜 계산`, which reads as date arithmetic: wording.md §7), `차폐 시설 -> 가림 시설`, `2,106개소에 -> 2,106곳에` | S01 §3 1.가.1) |
| G41 | Abbreviations: avoid; at first use write the full form, then the short one. Never show Roman letters or Chinese characters alone. | `지자체 -> 지방자치단체(이하 지자체)`, `AI 로봇 -> 인공 지능(AI) 로봇`, `R&D 과제 -> 연구 개발(R&D) 과제`, `합격자 限 -> 합격자에 한함`, `對美 수출 -> 대미 / 미국 대상 수출` | S01 §3 1.가.1) |
| G42 | Foreign words -> familiar Korean. | `브로슈어 -> 안내서, 소책자`, `키스 앤드 라이드 -> 환승 정차 구역`, `뉴노멀 시대에 맞춰 -> 새 일상 / 새 기준에 맞춰` | S01 §3 1.가.1) (more in wording.md §3b) |
| G43 | Hard Chinese-character words -> plain words. | `허가를 득하여 -> 허가를 받아 / 얻어`, `불인정될 수 있음 -> 인정되지 않을 수 있음`, `내수진작과 -> 국내 수요를 높이고` | S01 §3 1.가.1) |
| G44 | Too much nominalization: use particles and endings. | `적극 뒷받침하기 위해 -> 적극적으로 뒷받침하기 위해` | S01 §3 1.가.3) |
| G45 | Translation style, too much passive or causative. | `사정에 의해 변경될 -> 사정으로 변경될`, `도로로 사용 중에 있으나 -> 도로로 사용되고 있으나`, `환기를 시켜야 한다 -> 환기를 해야 한다`, `마무리되어진다 -> 마무리한다` | S01 §3 1.가.3) |
| G46 | For the public, do not write amounts in units of 천 원; write the usual 만 form. | `21,345천원 -> 2,134만 5천 원` | S01 §3 1.가.3) |

## 6. The reader's side  [S01 §3 3.]
| Id | Rule | Wrong -> right | Source |
|---|---|---|---|
| G50 | No overbearing endings: `~바람`, `~할 것`, `~음` read as orders. Use `~하기 바랍니다`, `~해 주시기 바랍니다`, `~해 주십시오`. | `전화로 문의 바람 -> 전화로 문의하기 바랍니다.`; `작성할 것 -> 작성해 주시기 바랍니다.` | S01 §3 3.가.1) (= wording EN3) |
| G51 | No authoritarian words. | `“……”라며 치하했다 -> “……”라고 말했다`, `영접하다 -> 맞이하다` | S01 §3 3.가.2) |
| G52 | No discriminatory words (sex, region, race, disability). | `결손가정`, `자매결연`, `절름발이 행정`, `학부형` | S01 §3 3.나.1) (more in wording.md §6) |
| G53 | Delete personal facts the text does not need. | `청소년 OOO(여, 18세) -> 청소년 OOO(18세)` | S01 §3 3.나.2) |
