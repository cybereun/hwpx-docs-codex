# hwpx-docs-forms

hwpx-docs의 선택 추가 플러그인입니다. 관공서 양식(법령 별지 서식 등)을 실제 양식에서 재어 만든 규칙 묶음(팩)을 담습니다. 필요한 사람만 설치하면 되고, 설치하지 않으면 본체 hwpx-docs는 그대로 가볍습니다.

## 하는 일

- 팩은 양식 하나의 복사본이 아닙니다. 쪽 크기와 여백, 글꼴과 크기, 이름 칸 음영, 선 굵기, 서식 번호 줄 같은 일반 규칙(프리셋)과 접수 칸, 신청인 표, 서명란, "○○○ 귀하", 처리 절차 상자 같은 재사용 부품으로 이루어집니다.
- 규칙마다 근거를 `n/N`으로 적습니다(예: `A4 세로 142/150`). 양식의 절반이 따르지 않는 규칙은 기본값에 넣지 않고 선택 값으로 둡니다.
- 쓰겠다고 고른 문서에만 적용합니다. 기본값으로 들어가지 않습니다.

## 들어 있는 팩

`law-forms`: 법령 별지 서식(law.go.kr 빈 양식 153개에서 잼). 기본 규칙 20개와 선택 규칙 6개이며 각 규칙의 근거는 `pack.py list packs/law-forms`로 봅니다.

- 기본: A4 세로 152/153, 여백 왼쪽·오른쪽 20mm 116/153, 위 20mm 114/153, 아래 10mm 122/153, 돋움 계열 127/153, 제목 16pt 119/153, 서식 번호 줄 8pt 99/146, 이름 칸 음영 #BBBBBB 48/89, 가는 선 0.12mm 93/147, 바깥 굵은 선 0.7mm 102/147.
- 부품(기본): 날짜 줄, 서명란, "○○ 귀하", 용지 규격 줄. 부품(선택, 절반 미만): 접수 칸, 신청인 표, 처리 절차 상자, 수수료 상자.
- 선택 값(`--with`): `small-print`(본문 8pt, 58/153), `line-160`(줄 간격 160%, 47/153).
- 확인: 양식 16개를 내용만 남긴 스펙에서 다시 만들어 한글 쪽 그림을 원본과 견줬을 때, 팩을 쓴 결과는 쪽 수가 16/16 같고 쓰지 않은 결과는 15/16이 같았습니다. 쪽별 잉크 차이 평균은 팩 53.5%, 쓰지 않은 결과 88.3%입니다. 팩 값과 다른 여백(15mm, 10mm)을 쓰는 양식은 여전히 크게 어긋납니다.

## 쓰는 법

1. Codex용 hwpx-docs를 설치하면 팩을 함께 사용할 수 있습니다.
2. “별지 서식 팩으로 신청서를 만들어 줘”라고 요청하거나 설치 폴더에서 아래 명령을 실행합니다.

   ```text
   python addons/hwpx-docs-forms/scripts/pack.py list addons/hwpx-docs-forms/packs/law-forms
   python addons/hwpx-docs-forms/scripts/pack.py apply spec.json addons/hwpx-docs-forms/packs/law-forms -o full.json
   python lib/hd.py build full.json out.hwpx
   ```

3. 원본 .hwp가 있으면 쪽 수와 쪽 그림을 원본과 비교합니다. 정답은 원본입니다.

## 폴더

| 경로 | 내용 |
|---|---|
| `packs/<팩>/` | `pack.json`(규칙과 근거), `preset.json`(값), `parts.json`(부품), `pagefit.json`(선택) |
| `scripts/pack.py` | 팩 합치기·부품 펼치기·검사(표준 라이브러리만) |
| `skills/hwpx-forms/` | 언제 쓰는지와 명령 순서 |

팩 형식은 본체 저장소의 `docs/forms-pack.md`에 있습니다. 규칙을 센 도구는 이 저장소 밖에 있어 설치본에도 저장소에도 들어 있지 않습니다.
