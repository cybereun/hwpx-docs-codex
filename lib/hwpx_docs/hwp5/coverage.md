# Coverage of the hwp5 package (binary .hwp, HWP 5.0)

Same idea as `docs/coverage.md`: what works, how it was checked, what is left. Rules HW01-HW113 are in `rules.md` of this folder.
Sample files are not shipped (third-party files); the self-test builds its own document. `hd hwp selftest DIR` runs the
file checks (rewrite with no change = same streams; one replaced letter keeps the form; the spec reads) on any folder.
