# What the 스타일마당 templates apply (Hangul 2024, ko-KR)

Measured 2026-11-14 with `hd textstyle samples templates <dir>` (Hangul Open of each template `.hwp` of the install folder
`Shared\HwpTemplate\Style\ko-KR\<Book|Letter|Paper|Present|Report|Thesis>\`, SaveAs HWPX; the install folder is only read) and
`hd textstyle styles <file>`. Facts only: no template file, font or asset is copied. A template is a set of 12 styles
(바탕글, 본문, 개요 1-7, 쪽 번호, 머리말, 각주) with their paragraph and character shapes; applying one in Hangul replaces the
document's style definitions. The COM action `StyleTemplate` (`HStyleTemplate.filename`) returns False, so Open + SaveAs is the
way to see them. The builder writes such a set with `named_styles` (rules.md TS12); fonts named here must exist on the PC.
Units: pt, line = percent. `left`, `indent`, `before`, `after` in pt.
